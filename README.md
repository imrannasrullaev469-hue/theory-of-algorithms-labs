## Как запустить

Нужен Python 3.10 или новее.

```bash
pip install -r requirements.txt
```

ЛР № 1 (только стандартная библиотека):

```bash
cd lab1
python lr1.py
```

ЛР № 2 и № 3 (замеры занимают около 1 и 3 минут, графики сохраняются в PNG рядом с программой):

```bash
cd lab2
python lr2.py
```

```bash
cd lab3
python lr3.py
```

Измерения в отчётах выполнены на Intel Xeon @ 2,10 ГГц (виртуальная машина, 4 vCPU), 16 ГБ ОЗУ, Linux, Python 3.13.
